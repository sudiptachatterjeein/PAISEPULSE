# Paisa Pulse 💹
Expense, income, savings and investment tracker. Installable PWA. Made with ❤️ by Sudipta Chatterjee · Seenvoy Media.

Static site: `index.html` + PWA files. Data is stored in the browser (localStorage) per mobile number.

## Deploy
1. Push this folder to a GitHub repo.
2. Vercel → Add New Project → import the repo → Framework "Other" → Deploy (no build command).
